# Contributing

First, thank you for considering contributing to **SSH over Mobile Hotspot**.

This project documents how to run Alpine Linux and OpenSSH on a rooted Android device and troubleshoot connectivity between devices connected to the same mobile hotspot.

---

## Ways to Contribute

Contributions are welcome in many forms, including:

- Bug reports
- Documentation improvements
- Typo corrections
- Shell script improvements
- Compatibility reports for different Android devices
- Additional troubleshooting steps
- Performance optimizations

---

## Before Opening an Issue

Please ensure you have:

- Read the documentation.
- Checked the FAQ.
- Followed the troubleshooting guide.
- Searched existing issues.

---

## Pull Requests

Please keep pull requests focused.

Examples of good pull requests:

- Fix a documentation error.
- Improve a script.
- Add support for another Android device.
- Improve formatting or readability.
- Add screenshots or diagrams.

Avoid combining unrelated changes into a single pull request.

---

## Documentation Style

When updating documentation:

- Use Markdown.
- Use proper headings.
- Include copy-and-paste command examples.
- Explain expected output.
- Add troubleshooting notes where appropriate.

---

## Code Style

Shell scripts should:

- Use POSIX-compatible shell where possible.
- Include comments for non-obvious logic.
- Avoid unnecessary dependencies.

---

## Reporting Bugs

Include:

- Android version
- Device model
- Root method
- Magisk version
- Alpine version
- Error messages
- Relevant logs
- Steps to reproduce

---

## Feature Requests

When requesting a new feature, explain:

- What problem it solves
- Why it would benefit other users
- Any alternative solutions considered

---

## Code of Conduct

Be respectful and constructive.

Everyone is welcome to contribute regardless of experience level.

---

Thank you for helping improve this project.
