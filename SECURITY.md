# Security Policy

Thank you for helping keep this project secure.

This repository primarily contains documentation and shell scripts for running Alpine Linux and OpenSSH on a rooted Android device.

---

# Supported Versions

Since this project is documentation-based, the latest version of the repository is considered the supported version.

Please refer to the latest commit before reporting an issue.

---

# Reporting a Security Issue

If you discover a security issue related to one of the scripts or configuration examples in this repository, please do **not** publish exploit details immediately.

Instead:

1. Open a **private security advisory** (if available), or
2. Contact the maintainer privately before creating a public issue.

Include:

- Android version
- Device model
- Magisk version
- Alpine version
- Steps to reproduce
- Logs (if applicable)

---

# Scope

This repository documents:

- Alpine Linux on Android
- OpenSSH configuration
- Magisk automation
- Network troubleshooting
- SSH connectivity

It is **not** intended to:

- Circumvent network security controls
- Provide offensive security tooling
- Document exploitation techniques
- Support unauthorized access to systems

---

# Best Practices

When using this project:

- Use strong passwords.
- Prefer SSH key authentication.
- Keep Alpine packages updated.
- Keep Magisk up to date.
- Restrict SSH access to trusted networks whenever possible.
- Disable password authentication if using SSH keys exclusively.

---

# Disclaimer

The examples in this repository are intended for educational purposes and for use on devices and networks you own or are authorized to manage.

Always comply with applicable laws, organizational policies, and the terms of service of the networks you use.
